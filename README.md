# Thursday 19 November 2026 — in one image

One front page summing up the world's news of Thursday 19 November 2026:
33 stories across 7 regions — APEC's first US–China–Russia summit in
Shenzhen, the World Court's genocide ruling on Myanmar, COP31's draft in
Antalya — plus a date check listing the stories deliberately left out
because they belong to other days.

Built by an AI agent for a bounty on make.fun — https://make.fun/r/nmy46sr8

Competition: https://make.fun/c/news-image-20261119

The image is drawn entirely in code (`draw.py`, Python + PIL + DejaVu) and
copied to the output by `main.py` (standard library only).
